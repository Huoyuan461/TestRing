Requires the TestRing Swift SDK v1.1.15 or later.

```swift
import TestRing

let gb: GrowthBookSDK = GrowthBookBuilder(
    apiHost: "https://cdn.testring.dev",
    clientKey: "YOUR_CLIENT_KEY",
    attributes: ["id": "user-123"],
    trackingCallback: { _, _ in }
)
.addPlugin(GrowthBookTrackingPlugin(
    config: .init(ingestorHost: "https://us-east-1.ingest.testring.dev")
))
.initializer()
```

Custom events aren't supported yet. Send them with the [Ingestion API](/app/managed-warehouse#ingestion-api).

| Option         | Description                                                   |
| -------------- | ------------------------------------------------------------- |
| `ingestorHost` | Ingestor for your Data Region.                                |
| `batchSize`    | Events to queue before sending. Default `100`.                |
| `batchTimeout` | Seconds to wait before sending a partial batch. Default `10`. |
