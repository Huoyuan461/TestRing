# Webflow Integration

Unleash the power of experimentation with TestRing to supercharge your Webflow site—no coding skills required!

<Info>
**Note**

This guide walks you through creating experiments using the TestRing AI Visual Editor, which requires a `Pro` subscription. [Learn More](https://www.testring.dev/pricing).

</Info>

## Let's Get Started

### Step 1: Create a TestRing SDK Connection

To connect your TestRing account to Webflow, you'll need to create a new SDK Connection and select the `Webflow` option. Before saving, confirm that you've enabled the toggles for `Include visual experiments in endpoint's response?` and `Include draft experiments`.

![Webflow SDK Connection in TestRing](/static/images/integrations/webflow/webflow-sdk-connection.png)

### Step 2: Add TestRing to Your Webflow Site

Once the SDK Connection is created, you should see a code snippet that you need to add to your site.

In a new window, log into your Webflow account, navigate to your site's settings, and select the `Custom Code` tab.

Find the "Head Code" section, and paste in the code snippet from TestRing. It should look something like this:

![Webflow Custom Code with the TestRing snippet in Head Code](/static/images/integrations/webflow/growthbook-webflow-edit-code.png)

<Info>
**Tracking experiment views**

When a user views an experiment, the code above will fire an event that tracks which variation the user saw. If you have Google Analytics 4 (GA4) or Segment installed on your site, you don't have to do any additional configuration. If, however, you need to use a different analytics provider, you can follow the [HTML Script Tag guide](/lib/script-tag).

</Info>

Once added, save and publish the changes and navigate back to TestRing.

### Step 3: Install the TestRing AI Visual Editor

Install the [TestRing AI Visual Editor](https://chromewebstore.google.com/detail/growthbook-visual-editor/nbomejknbpkcpjdagefhichaajpoempk) from the Chrome Web Store, then open the side panel and click **Connect with TestRing**. See [Install and connect](/app/visual/install-and-connect) for the full setup.

### Step 4: Create a TestRing AI Visual Editor Experiment

<Info>
**Questions about the AI Visual Editor?**

If you have questions about how to use the AI Visual Editor, see the [AI Visual Editor guide](/app/visual).

</Info>

Now that TestRing is installed on your Webflow site, you can create a new experiment using the AI Visual Editor.

First, navigate to "Experiments" on the left-hand navigation menu and then click "Create Experiment", before selecting "Design a New Experiment" and following the on-screen prompts.

Once you've created your experiment, select "AI Visual Editor" as the editor type and enter the URL of your Webflow site.

![AI Visual Editor on a Webflow site](/static/images/integrations/webflow/growthbook-webflow-visual-editor.png)

You'll then be redirected to your site, where you can use the AI Visual Editor to update your site's content.
